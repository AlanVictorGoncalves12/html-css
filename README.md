# Curso de HTML5 e CSS3 — Curso em Vídeo

Repositório criado para armazenar os **exercícios e desafios desenvolvidos durante o curso de HTML5 e CSS3** do canal **Curso em Vídeo**, ministrado pelo professor Gustavo Guanabara.

## 📚 Sobre o curso

O curso apresenta os fundamentos do desenvolvimento de páginas web utilizando **HTML5 e CSS3**, abordando desde a estrutura básica de uma página até conceitos de estilização, organização e responsividade.

### 📝 Conteúdos estudados

* Estrutura básica do HTML
* Tags HTML
* Títulos, parágrafos e formatação de textos
* Links e navegação
* Imagens
* Áudio e vídeo
* Listas
* Tabelas
* Formulários
* Semântica do HTML5
* CSS3
* Seletores
* Cores
* Fontes
* Box Model
* Bordas e sombras
* Gradientes
* Pseudo-classes e pseudo-elementos
* Flexbox
* Responsividade
* Desenvolvimento de páginas web

## 💻 Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **Visual Studio Code**
